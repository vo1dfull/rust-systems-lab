# Rust Systems Lab

A practical workspace for learning Rust through experimentation and systems-level projects.

## Focus Areas

- Rust Fundamentals & Ownership
- Memory Safety & Error Handling
- Data Structures & Algorithms
- Systems Programming
- Concurrency & Performance
- CLI Development

## Projects

Small experiments, utilities, and progressively more ambitious systems projects.

## Learning Approach

Understand the fundamentals. Write the code. Break things. Debug them. Build something useful.
